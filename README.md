# 🧠 ResumeLens

An AI-powered resume analyzer that scores your resume against any job description.

🔗 **Live Demo:** [PASTE YOUR STREAMLIT APP LINK HERE]
📸 **Screenshot:** [PASTE A SCREENSHOT OF YOUR APP HERE]

## 🎯 The Problem
Job seekers struggle to know if their resume matches a specific job description. 
This app uses AI to instantly show a match score, missing skills, and strengths.

## 🛠️ Tech Stack
- **Python** (Core logic)
- **Streamlit** (Web UI)
- **Google Gemini API** (LLM Analysis)
- **PyPDF** (Resume parsing)
- **CSS** (Custom styling)

## 🚀 Features
- Upload PDF resumes
- Paste any job description
- Get an instant match score (0-100)
- Identify missing skills and strengths

## 🏃 How to Run Locally
1. Clone the repo: `git clone <your-repo-url>`
2. Install libraries: `pip install -r requirements.txt`
3. Add your API key to a `.env` file: `GOOGLE_API_KEY=your_key_here`
4. Run the app: `streamlit run app.py`
