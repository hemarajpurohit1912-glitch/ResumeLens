# 🧠 ResumeLens
An AI-powered resume analyzer that helps job seekers match their resume to a job description.

## 🚀 Features (In Progress)
- [x] Read PDF resumes
- [x] Connect to Gemini LLM
- [ ] Match resume to job description
- [ ] Streamlit Web UI

## 🛠️ Tech Stack
- Python
- Google Gemini API
- Streamlit
- PyPDF

## 🏃 How to Run
1. Clone the repo: `git clone <your-repo-url>`
2. Install libraries: `pip install -r requirements.txt`
3. Create a `.env` file and add your API key: `GOOGLE_API_KEY=your_key_here`
4. Run the app: `python main.py`
